# Snakeball: 중독성 강화 및 게임플레이 고도화 전략 보고서
*(Addictive Gameplay Analysis & System Redesign Roadmap)*

---

## 1. 개요 및 분석 배경 (Executive Summary)

### 1.1 현재 게임 현황
**Snakeball**은 Three.js 기반 단일 파일로 빌드된 초경량 3D 캐주얼 엔드리스 러너입니다.
- **핵심 메커니즘**: 공 무리를 굴려 숫자 큐브를 파괴(공 개수 > 큐브 HP)하고, 벽/아이언 큐브/장애물을 회피하며 점수와 코인을 획득.
- **기술적 강점**: 240KB 수준의 가벼운 클라이언트, 견고한 서버 권위 경제/IAP/리더보드 시스템, iOS/Android/Toss 다중 플랫폼 지원.
- **현재 게임의 완성도**: 기본 조작, 충돌 물리, 콤보 사운드/시각 피드백, 상점 및 미션 시스템이 탄탄하게 구축되어 있습니다.

### 1.2 핵심 진단: "왜 3분 이상 플레이하지 않고 이탈하는가?"
> **"초반 30초의 진입성은 뛰어나지만, 플레이어를 몰입시키는 도파민 루프와 '한 판만 더'를 외치게 만드는 지속적 동기부여(성장·보상)가 부족합니다."**

현재 게임은 **방어적/위축형 플레이**(공을 잃지 않기 위해 피해 다니는 경험) 중심이며, 성공적인 중독성 게임들이 지닌 **공격적/확장형 쾌감**(기하급수적 성장, 파괴의 카타르시스, 피버 타임, 영구 성장)이 결여되어 있습니다.

## 2. 현재 Snakeball의 주요 문제점 및 한계 분석

```
[현재 경험 루프의 한계]
시작 (공 8개) ──> 큐브 충돌 (공 차감: 위축) ──> 장애물 회피 (스트레스) ──> 사망 ──> 처음부터 다시 (성장 잔여물 없음)
                                                                             │
                                                                             └──> "내가 강해진 게 없는데 굳이 또 해야 하나?"
```

### (1) 조작감의 한계 (Discrete Swipe vs Continuous Fluid Control)
- **문제점**: 현재 조작은 스와이프 1회당 1레인씩 이동하는 **이산적(Discrete) 스와이프 방식**입니다.
- **체감 피로도**: 모바일에서 레인을 여러 번 바꾸려면 화면을 계속해서 연타/반복 스와이프해야 하므로 손가락 피로도가 높고, 빠른 속도에서 미세 조작 미스로 인한 억울한 사망이 발생합니다.
- **트렌드와의 괴리**: 글로벌 흥행 러너 게임(Subway Surfers, Ball Run 2048, Count Masters)은 손가락을 떼지 않고 좌우로 부드럽게 미끄러지는 **연속적 드래그(Continuous Drag / Finger Tracking)** 방식을 채택합니다.

### (2) 감정선(Emotional Curve)의 불균형: "축소" 위주의 스트레스
- **문제점**: 큐브를 깰 때마다 내 소중한 공이 깎여나갑니다. 큐브를 부수는 것이 '성취'가 아니라 '내 자산의 손실'로 느껴져 플레이어가 큐브를 부수기보다 **피하는 것이 최선인 소극적 플레이**를 하게 됩니다.
- **카타르시스 부재**: 공이 50~100개로 불어났을 때의 시각적·물리적 압도감(화면을 가득 채우는 거대 볼 떼)이나, 큐브 무리를 시원하게 밀어버리는 '파괴의 쾌감'이 부족합니다.

### (3) 피버(Fever / Climax) 모드의 부재
- **문제점**: 메가볼 아이템이 유일한 무적 기믹이나, 4초 동안 단순히 빨라지고 부딪히면 깨지는 것에 그칩니다.
- **도파민 스파이크 부재**: 게임 내내 긴장감만 이어지고, 그 긴장을 일시에 해소해 주는 **폭발적 쾌감의 순간(Fever Time / Hyper State)**이 없어 플레이가 단조롭게 느껴집니다.

### (4) 시각적/환경적 단조로움 (Single Biome Fatigue)
- **문제점**: 검은 배경에 네온 고속도로 1종만 끝없이 이어집니다.
- **체감 한계**: 1,000점을 가든 5,000점을 가든 속도만 빨라질 뿐 주변 풍경, 도로 재질, 조명, 테마가 바뀌지 않아 2~3판만 해도 시각적 피로감이 극에 달합니다.

### (5) 메타 프로그레션(영구 성장)의 부재
- **문제점**: 코인/젬을 모아 살 수 있는 것이 **스킨(외형)**과 **소모성 아이템 3종**뿐입니다.
- **리텐션 붕괴**: 로그라이트/하이퍼캐주얼의 핵심인 "비록 이번 판에 죽었지만 코인을 모아 기본 능력치를 업그레이드했으니 다음 판은 더 멀리 갈 수 있다"는 **영구 성장 루프(Talent Tree)**가 없습니다.

### (6) 사운드 및 리듬적 도파민 부족
- **문제점**: BGM이 기본 OFF이며, Web Audio 기본 오실레이터로 구성된 타격음(Sawtooth/Square)이 밋밋합니다.
- **ASMR 쾌감 부재**: 큐브를 연속으로 깰 때 피아노/실로폰의 펜타토닉 음계가 청량하게 연주되는 형태의 '음악적 타격감'이 약합니다.

## 4. Snakeball 중독성 극대화를 위한 6대 핵심 개선 전략

```
                   ┌─────────────────────────────────────────┐
                   │  SNAKEBALL ADDICTION ENGINE FRAMEWORK   │
                   └─────────────────────────────────────────┘
                                        │
     ┌──────────────────┬───────────────┴───────────────┬──────────────────┐
     ▼                  ▼                               ▼                  ▼
【1. 조작 & 물리】   【2. 인게임 쾌감】             【3. 환경 & 완급】   【4. 영구 성장 메타】
 - 아날로그 드래그    - 연산 게이트 (+10, x2)         - 4단계 바이옴 순환   - 영구 특성 트리
 - 젤리 물리 군집     - 슈퍼 피버 (Fever Time)        - 보스 큐브 / 마일스톤 - 스킨별 고유 패시브
 - 다이내믹 볼 스케일 - ASMR 멜로딕 타격음            - 라이벌 추월 깃발    - 일일 챌린지 모드
```

---

### Pillar 1. 조작감 및 물리 엔진 혁신 (Fluid Control & Jelly Physics)

1. **연속적 드래그 조작 (Continuous Fluid Drag)**
   - 스와이프를 연타하지 않고, **화면에 손가락을 대고 좌우로 움직이는 만큼 공 무리가 즉각 부드럽게 추종**하는 방식 도입.
   - 손가락을 빠르게 튕기면 관성(Inertia)으로 부드럽게 감속.
   - *설정에서 기존 'Classic Swipe'와 신규 'Smooth Drag' 선택 가능하도록 제공.*

2. **공 군집의 젤리/스프링 물리 (Jelly Swarm Physics)**
   - 공이 많아지면 딱딱한 대형이 아니라, 방향 전환 시 **물풍선처럼 쫀득하게 쏠렸다가 복원되는 젤리(Spring-Damper) 물리 효과** 부여.
   - 좁은 틈을 지날 때 공들이 길쭉하게 모였다가 넓은 곳에서 촤르륵 퍼지는 유체역학적 쾌감.

3. **공 개수에 따른 비주얼 스케일링 (Dynamic Scale & Glow)**
   - 공 개수가 10개 미만: 작고 빠른 민첩한 형태.
   - 공 개수가 30개 이상: 메인 볼이 거대해지고 주변에 황금빛 오라 발생.
   - 공 개수가 60개 이상: **"JUGGERNAUT BALL"** 상태로 변하여 지면을 쿵쿵 울리며 큐브를 가볍게 분쇄.

---

### Pillar 2. "파괴와 증식"의 카타르시스 루프 (Gates & Super Fever)

#### (1) 연산 게이트 (Math Multiplier Gates)
도로 위에 반투명 홀로그램 게이트가 나타나 좌우 선택을 유도:
- **왼쪽 게이트**: `+15 BALLS` (안전한 선택)
- **오른쪽 게이트**: `×2 BALLS` (현재 공이 15개 이상이면 대박, 미만이면 손해)
- 순간적인 암산과 판단으로 공이 순식간에 20개 → 40개 → 80개로 불어나는 **폭발적 도파민**.

#### (2) 슈퍼 피버 모드 (SUPER FEVER TIME)
- **발동 조건**: 큐브를 연속 파괴하여 **콤보 10회**를 달성하거나, 도로 위의 **피버 스타(Fever Star)** 3개를 수집했을 때.
- **피버 연출**:
  1. 화면이 순간 멈추며(0.1s 히트스톱) 웅장한 사운드와 함께 **화면 테두리에 네온 불꽃 이펙트(Screen Glow FX)** 폭발.
  2. 배경 음악이 경쾌한 드럼비트로 전환.
  3. 공 무리가 거대한 **골든 불사조/용** 형태로 뭉쳐 5초 동안 **초고속 무적 돌진**.
  4. 전방의 모든 큐브와 장애물이 팝콘처럼 터지며 대량의 점수와 코인 자동 흡수.
- **플레이어 경험**: "콤보를 끊기지 않고 10개만 채우면 피버가 터진다!"라는 강력한 단기 목표 부여.

#### (3) 멜로딕 ASMR 타격음 (Musical Combos)
- 큐브를 부술 때마다 단순 타격음 대신 **맑은 펜타토닉(도-레-미-솔-라-도) 음계**가 콤보에 맞춰 순차적으로 연주됨.
- 5연타, 8연타로 큐브를 연속 격파할 때 마치 피아노 글리산도를 치는 듯한 **청각적 황홀경(Juice)** 제공.

### Pillar 3. 환경의 다채로움과 보스전 (Biomes & Climax Pacing)

#### (1) 4대 테마 바이옴 자동 전환 시스템
런 진행 거리에 따라 도로와 배경, 조명이 자연스럽게 모핑(Transition):
1. **0m ~ 1,000m (Cyber Highway)**: 현재의 세련된 딥블루 & 민트 네온.
2. **1,000m ~ 2,500m (Synthwave Sunset)**: 붉은 석양 노을, 레트로 핑크/오렌지 그리드 도로, 야자수 실루엣.
3. **2,500m ~ 4,500m (Quantum Void)**: 우주 성운 배경, 반투명 유리 도로, 부유하는 기하학적 큐브들.
4. **4,500m+ (Lava Core)**: 붉은 용암이 흐르는 고난도 지옥불 도로.

#### (2) 보스 큐브 & 브레이크 월 (Boss Battles & Bonus Walls)
- **매 1,000m 지점**: 도로 전폭을 가로막는 **거대 보스 큐브(HP 50~100)** 등장.
  - 전방 200m 구간에 프리볼 아이템을 집중 배치하여 "공을 최대한 모아 보스를 한 방에 격파하라!"는 긴장감 조성.
  - 격파 성공 시 대량의 코인 분수와 함께 다음 바이옴으로 워프.
- **피니시 보너스 존**: 보스를 뚫은 직후 **"코인 벽 보너스 존"**이 펼쳐져 남은 공 개수만큼 코인 벽을 연속으로 뚫으며 추가 점수 획득.

#### (3) 실시간 라이벌 추월 깃발 (In-Run Rival Ghosts)
- 도로 옆에 **"Mark: 1,520점"**, **"User_99: 2,100점"** 같은 리더보드 플레이어들의 깃발과 아바타 마커가 세워져 있음.
- 해당 지점을 통과할 때 **"RANK UP! 14위 돌파!"** 팝업과 함께 팡파르 연출 → 소셜 경쟁심 극대화.

### Pillar 4. 영구 성장 메타 시스템 (Roguelite Talent Tree)

플레이어가 사망해도 허무함을 느끼지 않고 "다음 판엔 더 세진다"는 확신을 주는 핵심 시스템입니다.

```
[연구소 (Talent Tree) 업그레이드 항목]
┌─────────────────────────┬────────────────────────────┬─────────────────────────┐
│   1. 시작 볼 수량       │   2. 코인 획득 배율         │   3. 자석 흡입력 & 시간  │
│   (기본 8개 → 최대 25개) │   (1.0x → 최대 2.5x)       │   (범위 +100%, 시간 +5s)│
├─────────────────────────┼────────────────────────────┼─────────────────────────┤
│   4. 피버 지속시간       │   5. 크리티컬 파괴 확률     │   6. 콤보 유지 시간      │
│   (5초 → 최대 10초)     │   (5% 확률로 큐브 공 소모0) │   (3초 → 최대 6초)      │
└─────────────────────────┴────────────────────────────┴─────────────────────────┘
```

- **코인 소모처 확대**: 스킨을 다 산 유저도 지속적으로 코인을 소모할 곳이 생김.
- **수익화(BM) 연계**:
  - 특성 업그레이드 비용이 단계별로 상승(500 → 1,500 → 4,000 코인).
  - 유저는 "코인이 조금 모자란데?" 할 때 **결과창 코인 2배 광고(Double Coins)**나 **코인 IAP 패키지**를 기꺼이 결제하게 됨.

### Pillar 5. 스킨별 고유 특수 능력 (Character Identity)
